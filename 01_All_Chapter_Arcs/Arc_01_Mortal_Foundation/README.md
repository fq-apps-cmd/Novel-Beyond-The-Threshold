- All non-cover pages (2-245) were assigned to a chapter or reference file.
- The cover, OneNote timestamps, page footers, and note-header word counts
  were omitted. Body text, including editing comments, was not rewritten.
- PDF line wrapping is retained using Markdown hard line breaks.
  Rich formatting and original paragraph structure may need manual cleanup.
- Note titles and headings inside the prose sometimes differ. Both are
  retained; filenames use the OneNote note title. The title-correction
  note is linked below rather than applied automatically.
- Chapter 22 Part 1 includes source editing comments and a source link
  on PDF pages 98-99. Some comments appear truncated in the export;
  they have been preserved as extracted, not reconstructed.
- Repeated text at PDF page boundaries is retained, not deduplicated.
- The original PDF was not modified.
