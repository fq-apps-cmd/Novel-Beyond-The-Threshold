# Backups & Archive

## Organization

Use this section to preserve:
- Old chapter versions
- Deleted scenes (might be useful later)
- Alternate fight scenes / outcomes
- Early notes and brainstorms
- Retconned systems or mechanics
- Previous plot ideas that were changed
- Character concept art / descriptions (old versions)
- Scrapped subplots

## Why Keep Backups?

1. **Safety** - Never lose work
2. **Inspiration** - Old ideas might work in different context
3. **Reference** - See how story evolved
4. **Recovery** - Restore deleted scenes if needed
5. **Learning** - Compare draft versions

---

## Backup Protocol

When making major changes:
1. Copy old version to appropriate folder
2. Add date and description
3. Note why it was changed
4. Keep indefinitely (storage is cheap)
