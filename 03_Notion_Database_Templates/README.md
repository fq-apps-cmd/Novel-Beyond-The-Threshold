# 📊 Notion-Style Database Templates

This folder contains database-style templates you can recreate in Notion.
Each file represents one database with its properties and sample entries.

| File | Database Name | Purpose |
|------|--------------|----------|
| [A_Chapters.md](A_Chapters.md) | Chapters | Track every chapter with arc, POV, status, and reveals |
| [B_Characters.md](B_Characters.md) | Characters | Full character registry with traits, secrets, and arc role |
| [C_Herbs_And_Materials.md](C_Herbs_And_Materials.md) | Herbs & Materials | All herbs with tier, element, behavior, and usage |
| [D_Recipes_And_Formulas.md](D_Recipes_And_Formulas.md) | Recipes & Formulas | Alchemy recipes with ingredients, effects, and risk |
| [E_Cultivation_Progression.md](E_Cultivation_Progression.md) | Cultivation Progression | Realm stages, body/meridian changes, breakthrough risks |
| [F_Locations.md](F_Locations.md) | Locations | All story locations with atmosphere and tied characters |
| [G_Story_Arcs.md](G_Story_Arcs.md) | Story Arcs | Arc overview with tone, reveals, and setup for next arc |
